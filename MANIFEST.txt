     ↳ Умное разбиение текста на куски

     ↳ Сохранение смысловых границ

     ↳ Работа с PostgreSQL через SQLAlchemy
     ↳ CRUD операции для всех сущностей

  🔧 models.py (4.8K, 250+ строк)

     ↳ Enums для языков и интервалов

  🔧 tasks.py (6.9K, 300+ строк)
     ↳ Celery приложение и асинхронные задачи
     ↳ Планирование отправок (Beat schedule)

🔐 ТЕХНОЛОГИЧЕСКИЙ СТЕК:

    - Python 3.11
